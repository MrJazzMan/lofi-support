# Lofi Radio — Suporte / Support

## Português

Responsável: **Miguel Garcia**. Contacto: **miguelopesgarcia+lofi@gmail.com**.

A Lofi Radio é um leitor para Cascais FM e Lofi; não é a emissora. A programação, eventuais anúncios nas emissões e disponibilidade dependem dos operadores das rádios.

Para obter ajuda, envie a versão e build indicadas em Definições → Sobre, modelo do dispositivo, versão do sistema, estação e descrição do problema. Não envie palavras-passe, chaves, informação sensível ou gravações de áudio.

Se não houver som, confirme a ligação à Internet e o volume. Não desative a segurança TLS, instale certificados ou apague os dados da app para um teste inicial. Na candidata mais recente, os comandos seguinte/anterior não mudam de estação em Cascais FM, que é uma emissão em direto; use o seletor para trocar de rádio. O arranque frio tenta iniciar Lofi automaticamente: ajuste o volume antes de abrir.

Questões de privacidade, conteúdo ou pedidos de remoção podem ser enviados para o mesmo contacto. Consulte a página de privacidade disponibilizada em conjunto com esta página. Não se promete um prazo fixo de resposta.

## English

Responsible party: **Miguel Garcia**. Contact: **miguelopesgarcia+lofi@gmail.com**.

Lofi Radio is a player for Cascais FM and Lofi, not the broadcaster. Programming, any advertisements contained in streams and availability depend on the radio operators.

For support, include the version/build shown in Settings → About, device model, operating-system version, station and a description of the issue. Do not send passwords, keys, sensitive information or audio recordings.

If there is no sound, check your Internet connection and volume. Do not disable TLS security, install certificates or delete app data as an initial troubleshooting step. In the latest candidate, next/previous do not switch stations on the live Cascais FM stream; use the station selector. Cold launch attempts to start Lofi automatically: set a comfortable volume before opening.

Send privacy, content or removal enquiries to the same contact. Consult the privacy page provided alongside this page. No fixed response time is promised.
